# Elite Dangerous: Log Parser & Router Sync [CMDR Edition] 🚀

Аутентичная утилита автоматизации сетевой безопасности и устранения проблемы «островов» для пилотов **Elite Dangerous**, стилизованная под оригинальный бортовой интерфейс кораблей Frontier.

## 🔍 Описание проблемы

Из-за особенностей P2P-архитектуры игры, блокировок, фильтрации трафика и работы DPI у некоторых провайдеров на территории РФ, игроки часто оказываются на изолированных «островах»: не видят других пилотов в суперкруизе, не могут нормально крылить, стыковаться на станциях или ловят бесконечные ошибки транзакций (`Black Adder`, `Taupe Cobra`, `Magenta Krait`).

Эта программа в реальном времени отслеживает сетевую активность игрового клиента по журналам `netLog`, отсекает мусорные и локальные IP-адреса по черному списку исключений, а боевые IP хостов динамически отправляет на ваши маршрутизаторы для стабилизации сетевых маршрутов.

## 💎 Ключевые особенности
* **Современный REST API (v7+):** Все команды улетают через HTTP(S) PUT-запросы.
* **Синхронизация таймаутов («Анти-Петля»):** При работе с несколькими роутерами программа считывает и выравнивает оставшееся время жизни (`timeout`) динамических хостов `/32` (на 7 дней). Адреса удаляются из файрволов одновременно, исключая бесконечную петлю пересылок между Mikrotik.
* **Умный черный список:** Файл `filters.txt` поддерживает вложенные логические группы и построчные комментарии через `#`. Комментарии красиво подсвечиваются курсивом в меню настроек. При вводе IP автоматически проверяются маски подсетей (например, маска `/8` заблокирует дубли хостов).
* **Anti-Freeze Движок:** Пакетный анализ тяжелых исторических файлов и живой ежесекундный мониторинг («Tail -f») запущены в фоновых потоках ОС (`Task.Run`), обеспечивая плавный и интерактивный UI.
* **Экспорт для других роутеров:** Таблица поддерживает контекстное меню по правому клику мыши. Пилот может в один клик выгрузить сводный список уникальных IP в файл `ed_filters_дата_время.txt` для ручного импорта в роутеры Keenetic, ASUS или TP-Link.
* **Безопасность данных:** Конфигурация профилей роутеров полностью зашифрована криптографическим механизмом Windows DPAPI (`ProtectedData`) на уровне учетной записи текущего пользователя Windows.

## 🛠 Подготовка маршрутизатора Mikrotik

1. Наличие RouterOS v7.1 или выше.
2. Включенный сервис REST API (Вкладка `IP` -> `Services` -> `rest` должен быть активен, стандартный порт HTTPS `443`).
3. Учетная запись пользователя Mikrotik с правами на запись (`write`) в списки Firewall.

## 📁 Структура каталогов

Программа использует строгое разделение путей через `Path.Combine`:
* Папка логов игры (автоопределяется при старте через Saved Games / Steam): `C:\Users\<Имя>\Saved Games\Frontier Developments\Elite Dangerous\`
* Локальное хранилище данных приложения: `Documents\EDIPSearch\`
  * `filters.txt` — черный список исключений.
  * `routers.dat` — зашифрованный файл конфигурации подключенных роутеров.
